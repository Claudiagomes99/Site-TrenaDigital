# Trena Laser Inteligente
---

## Objetivo

Desenvolver um dispositivo IoT capaz de realizar medições de distância e ângulo, permitindo o armazenamento e gerenciamento das informações por meio de um site.

## Tecnologias utilizadas

- PHP
- MySQL
- XAMPP

## Funcionalidades do site

- Página inicial com informações das medições.
- Cadastro de visitantes.
- Cadastro de medições.
- Consulta, edição e exclusão de registros.
- Integração com API em PHP.

## Banco de Dados

O sistema utiliza MySQL e possui duas tabelas principais:

- **Visitantes:** armazena os dados dos visitantes.
- **Medições:** armazena as informações de distância e ângulo.

## Operações CRUD

O sistema permite:

- Create: cadastrar informações.
- Read: consultar registros.
- Update: editar informações.
- Delete: excluir registros.
